# Modelo de Ajuste de Datos - Período de un Péndulo

Proyecto desarrollado en **Python** para el curso de **Modelamiento Matemático** (Universidad del Valle), enfocado en el análisis, ajuste de curvas y modelado matemático del período de oscilación de un péndulo a partir de datos experimentales.

## Contenido del repositorio

* `Taller03_Grupo01.ipynb`: Cuaderno de Jupyter con el procesamiento de datos, ajuste del modelo matemático, cálculo de parámetros, análisis de error y visualización gráfica de resultados.
* `.gitignore`: Configuración de exclusión de archivos temporales y entornos virtuales.

## Herramientas utilizadas

* **Python 3**
* **Jupyter Notebook**
* **NumPy** y **SciPy** (cálculo numérico y ajuste de datos)
* **Matplotlib** (visualización y gráficas)
